### 🤖 Building with AI (without the vibes-only coding 😌)

I use AI coding agents every day, and I treat them like a teammate who needs a really good brief and a really good test suite!

- **Context engineering:** agents get the same onboarding a new dev would. In [Cairn](https://github.com/lekaren-web/cairn-ui), an [`AGENTS.md`](https://github.com/lekaren-web/cairn-ui/blob/main/AGENTS.md) explains the architecture, the Web Component gotchas, and what "done" actually means
- **Harness engineering:** the rules aren't just vibes, they're checks! A [contract test](https://github.com/lekaren-web/cairn-ui/blob/main/tests/contract.test.ts) fails if a component skips its story, its axe test, or the design tokens, and a Claude Code hook won't let an agent finish while `npm run verify` is failing 🚦
- **Same gate for everyone:** that exact check runs in GitHub Actions on every push, so agent code and my code have to pass the same bar 💪
- **Day to day:** Claude Code, Cursor and Codex, plus the shared agent toolkit (skills, playbooks, scripts) we keep in the repo at Medtrics
